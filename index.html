Guía rápida

Cómo usar TechNexus XR

1. Importa un modelo GLB desde tu equipo o pega una URL pública que permita CORS.
2. Explora el modelo con el ratón o los gestos táctiles; ajusta escala e iluminación.
3. Prueba RA desde un móvil compatible y RV desde un navegador con WebXR.
4. Diseña una misión, añade puntos de interés y descarga la ficha pedagógica.
5. El copiloto crea un prompt que puedes copiar a tu asistente de IA favorito.

Para publicar en GitHub Pages: sube este archivo como index.html y habilita Pages. Las funciones de cámara y XR requieren HTTPS y permisos compatibles.
